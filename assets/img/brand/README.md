# 见闻周刊 · 视觉标识

## 图标寓意

一版刊物的形状（右上折角 = 印刷品的折页），内里一只**眼睛**的留白，眼睛下方一行**正文**。

- 眼睛 = 「见」：看到的世界
- 一行正文 = 「闻」与「周刊」：被记录下来、按期发布的东西
- 折角 = 纸，不是屏幕；这是刊物而不是 App

三个元素在 16px 时退化成一个带眼的方版，仍可辨认；512px 时才看到折角与正文行。

## 颜色

| 用途 | 浅色底 | 深色底 |
|---|---|---|
| 版（plate） | `#0b6e4f` 墨绿 | `#14795a` |
| 眼白（paper） | `#fbfaf7` | `#f2f1ec` |
| 瞳孔（dot） | 同版色 | 同版色 |

墨绿取自站点强调色 `--accent`，与正文链接同色系，避免品牌色和交互色打架。
瞳孔刻意用版色而不是纯黑：远看是「眼底的一点」，近看才是一个洞。

## 文件

| 文件 | 用途 |
|---|---|
| `icon.svg` | 主图标（favicon / 顶栏 / 页脚）。内置 `prefers-color-scheme`，深色环境下自动换浅底的版色 |
| `icon-app.svg` | App 图标（版铺满画布，iOS/Android 自行裁圆角） |
| `icon-512.png` / `icon-192.png` | PWA / Android 图标 |
| `apple-touch-icon.png` | iOS 主屏图标（180px） |
| `logo.svg` | 横版标志（浅色底）：图标 + 见闻周刊 + WEEKLY · HARD SOURCES |
| `logo-dark.svg` | 横版标志（深色底） |
| `og/<期号>.png` | 每期社交分享卡 1200×630（含本期标题、三个数字） |
| `logo-preview.png` | 横版标志的位图预览（给不支持 SVG 的场合） |

## 用法

- 网页里一律用 `icon.svg`（保留透明与自适应），不要用 PNG 放大缩小。
- 横版标志按底色二选一，别在深色底上用 `logo.svg`（字会看不见）。
- 最小尺寸：图标 16px，横版 240px 宽；再小就去掉副标题。
- 不要改比例、不要加投影、不要把眼白换成白色以外的高饱和色。

## 生成方式

图标与标志都是手写 SVG（无字体依赖，除横版里的中文用系统衬线体）。
位图用 macOS 的 QuickLook 渲染：`qlmanage -t -s 1024 -o /tmp icon-app.svg`，再用 `sips` 缩到目标尺寸。
分享卡是 1200×630 的 HTML 用无头浏览器截图，模板逻辑已固化在
`~/.hermes/skills/research/sourced-news-brief/scripts/build_site.py` 之外的 `_og.html` 草稿里，可按期复制改文案。
